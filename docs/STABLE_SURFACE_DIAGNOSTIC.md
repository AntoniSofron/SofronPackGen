# Stable-surface diagnostic baseline

This branch **temporarily disables all custom cave and underground-channel carving** in final density. The definitions remain available for later repair. It is a controlled isolation test, not a full fix or release.

## Why

Screenshots show exposed underground biomes, enormous open rock basins, cliff-like boundaries, and Distant Horizons water LOD that disappears in actual chunks. The current final density takes a minimum with cave fields; this can produce large open spaces and expose cave biome decorations at the surface. To test that hypothesis, final density now uses only the topographic solid field plus bounded karst.

## Test protocol

1. Use a **new world** with the updated JAR. Do not reuse chunks generated by previous versions.
2. Temporarily disable Distant Horizons and other worldgen mods, retaining only Fabric Loader/API and Sofron Pack Gen.
3. Compare the same seed and locations against the previous build.
4. Check whether exposed underground biomes and voids disappear. Also check actual water blocks at sea level Y=64.
5. Capture F3 debug screen and latest.log if defects persist.

## Remaining limitations

This branch intentionally disables custom caves and underground rivers. It does not fix missing surface water, river flow, lake fill, surface rules, climate/biome matching, or unrealistic stone patches. No runtime verification has been performed. Do not merge as a final feature-complete implementation.
